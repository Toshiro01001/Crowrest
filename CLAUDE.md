# SIIC · Crowsrest

Site em GitHub Pages da campanha de Candela Obscura em Crowsrest: terminal policial no estilo Windows 95, em tempo real, com mapa da cidade, fichas e investigação.

## Como este projeto funciona

- O repositório e a pasta ainda se chamam Crowrest, mas o nome da cidade é Crowsrest.
- Leia o `README.md`: ele descreve cada arquivo, a configuração e onde ficam os dados.
- HTML, CSS e JavaScript em arquivos soltos, sem build. O projeto Firebase é próprio, separado do da Planta da Caixa.
- O que não foi revelado aos jogadores mora no servidor. Nunca envie ao repositório `segredos-crowsrest.json` nem `regras-firebase-crowsrest.json`.
- A versão aparece no rodapé e nos `?v=` do `index.html`. Atualize as duas ao publicar.

- Ao terminar uma alteração, entregue a mensagem de commit em dois blocos rotulados: "Título" (até 50 caracteres) e "Descrição" (estendida, com exatamente o que foi feito).
- Entregue arquivos soltos, nunca em `.zip`.
- O repositório é público: não coloque senhas, chaves secretas nem dados pessoais em arquivos versionados.
